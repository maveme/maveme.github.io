abstract: |
      Software-based art is highly vulnerable to digital obsolescence, and studying its evolution requires clean datasets. 
      Mining open-source platforms (e.g., GitHub, OpenProcessing) for curating software-based creative code (e.g., p5.js sketches) is hindered because repositories are overwhelmingly dominated by educational boilerplate, homework, and tutorials. 
      Traditional software engineering and MSR metrics (e.g., commit activity, contributor count) cannot be used for curation because they do not capture artistic intent.
      Therefore, we present a vision for a multimodal agentic pipeline that combines static code analysis, headless visual rendering, and an LLM-as-a-judge architecture to curate a gold-standard software-based artwork dataset. This framework unlocks systematic software evolution, dependency decay analysis, and maintenance research to preserve digital cultural heritage.
